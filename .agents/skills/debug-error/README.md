# Debug Error Skill

## Description
Systematic debugging workflow for investigating errors, identifying root causes, implementing fixes, and preventing regressions.

## Usage Examples
- "Help me debug this stack trace and find the root cause."
- "Troubleshoot why this API fails only in production."
- "Investigate this bug and propose a safe fix with tests."
- "This exception is intermittent — debug it step by step."
