# Write Tests Skill

## Description
Creates unit, integration, component, and end-to-end tests that follow project conventions, validate critical behavior, and improve reliability.

## Usage Examples
- "Write unit tests for this service class."
- "Add integration tests for this API endpoint."
- "Create Vitest coverage for this TypeScript package."
- "Add Playwright tests for the critical browser flow."
- "Add missing tests to improve coverage for this module."

## TypeScript runner references

TypeScript guidance is composable: load `references/typescript.md` for cross-runner test-authoring rules, then load every matching runner reference for Vitest, Jest, Node test, Bun test, or Playwright. Repository conventions and installed-version behavior remain authoritative.
