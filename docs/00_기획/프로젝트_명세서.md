# SCHAT 프로젝트 명세서

요구사항과 설계 판정의 기준으로 사용하지 않는다.

- 현재 요구사항: [`통합_요구사항서.md`](../02_요구사항/통합_요구사항서.md)
- 전체 구조: [`시스템_구조_요약.md`](../03_설계/시스템_구조_요약.md)

현재 공식 안정 복구 기준점은 `v0.9`다. 현재 코드는 최종 READY 재판정 전 상태이며,
운영 UAT 36/36과 retrieval 무회귀를 확인했다. Positive Gold는 21건 승인·11건 deferred,
TF027은 10개 항목의 1차 사람 검수를 마쳤으나 최종 판정은 reject로 Production에서 제외했다.
Provider/LLM judge 평가는 승인 범위가 남아 pending이다. 사용자 승인 없이 commit, tag,
push하지 않는다.
