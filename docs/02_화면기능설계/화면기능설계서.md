# 화면·기능설계서

기준일: 2026-09-17 · 현재 작업 트리 기준 · 실제 브라우저 검증 미실시

공통 UI의 정본이다. 현재 코드에는 검색 엔진 선택 기능이 없으므로 버전별 화면을 복제하지 않는다. 아래 ‘향후 기능’은 구현 여부와 확인할 사항이며 개발 확약이 아니다.

## SCR-001 로그인·최초 설정

- 목적/사용자: 직원·관리자 인증. 최초 로컬 실행에서는 관리자 계정 생성.
- 입력: 로컬 아이디 또는 운영 직원 이메일, 비밀번호. 최초 생성 시 비밀번호 확인.
- 버튼: 관리자 계정 만들기, 로그인.
- 출력: 로그인 폼, 안내, 실패 메시지. 직원 연결 설정이 없으면 ‘직원 전용 로그인 설정이 필요합니다’ 표시.
- 이동: 인증 성공 → SCR-002. 로그아웃 → 이 화면.
- 예외: 불일치·비활성 계정·권한 만료·로컬 로그인 시도 제한. 로컬 모드는 loopback 주소에서만 허용.
- 상태: 구현. 실제 사용자 계정은 조사하지 않음.
- 향후: 비밀번호 재설정 UI 미구현.
- 관련: REQ-001, `app.py`, `auth.py`, `cloud.py`.

## SCR-002 질문·대화

- 목적/사용자: 직원과 관리자가 지침에 관해 질문.
- 입력: 최대 500자 질문, 대화가 있을 때 ‘이전 질문에 이어서 묻기’.
- 버튼: 전송, 추천 질문 4개, 새 대화 시작, 최근 질문 이동, 로그아웃. 관리자에게 지침서 관리 이동 제공.
- 출력: 첫 화면 중앙 ‘무엇을 도와드릴까요?’, 둥근 입력창, 아래 ‘어떤 지침을 확인할까요?’와 작은 추천 질문. 중앙 영역 최대 너비 680px. 이는 기존 미커밋 UI 변경 기준이다.
- 동작: 추천 질문은 입력칸을 채운다. 별도 AI 호출로 추천 문구를 생성하지 않는다. 문서 정보가 부족하면 고정 예시로 채우므로 추천 문구 자체가 근거 존재를 뜻하지 않는다.
- 이동: 전송 → 같은 화면의 SCR-003. 새 대화 → 대화 초기화. 기록은 세션에서 최근 최대 8턴 유지.
- 예외: 문서 없음 → 입력은 가능하지만 등록 안내 후 검색·LLM 실행 중단. 관리자에게 ‘지침서 등록하러 가기’ 표시. 빈 질문·개인정보 의심·모호한 후속 질문은 안내. 명백한 업무 외 질문은 거절.
- 상태: 구현. 새로고침·재접속 시 대화 영구 보존 기능은 없음.
- 향후: 엔진 선택 UI, 사용자 대화 영구 저장은 미구현.
- 관련: REQ-002/003/009/010, `app.py`, `ui.py`, `ui.css`, `query.py`.

## SCR-003 답변 결과

- 목적/사용자: 질문자에게 검증된 답변 또는 거절·오류 안내 제공.
- 입력: 제출 질문과 검색 결과(시스템 내부).
- 버튼: 출처 열기, 조건에 따라 체크리스트 열기, 답변 검토 요청, 대기 시간이 있는 오류의 같은 질문 다시 시도.
- 출력: 문장·목록·절차·비교 형식, 문장별 인용 번호, 근거 문서 수, 개정일, 처리 시간. 근거 불충분 시 ‘등록된 지침서에서 확인할 수 없습니다.’
- 이동: 출처 → SCR-004. 검토 요청 → 완료 알림. 재시도 → 동일 질문 처리.
- 예외: API 연결·인증·한도 오류. AI 답변이 없을 때 검색된 참고 원문을 별도로 표시할 수 있음. 충돌 근거는 경고 및 양쪽 출처로 표시.
- 상태: 구현. 관리자는 답변 아래 BM25 디버그 결과와 CSV 다운로드도 확인 가능.
- 향후: 검토 요청의 처리 상태 조회·운영자 처리 UI 미구현.
- 관련: REQ-004/005/010/011, `answer_ui.py`, `app.py`, `diagnostic_ui.py`.

## SCR-004 근거 원문·승인 체크리스트 대화상자

- 목적/사용자: 답변 원문 대조와 저장된 승인 항목 확인.
- 입력: 선택한 출처, 앞뒤 문단 토글, 체크리스트 체크박스.
- 버튼: 출처 열기, 검색된 원문 전체 보기, 앞뒤 문단도 보기, 체크리스트 열기.
- 출력: 문서·항목·페이지/위치·개정일, 인용 문장, 해당 chunk 전체, 조건에 맞는 이웃 문단. 체크리스트는 연결된 문서 원문 항목.
- 이동: 대화상자를 닫으면 답변으로 복귀.
- 예외: 문서 버전 변경·권한 만료 시 중단. 체크리스트가 없으면 열기 버튼이 나타나지 않음.
- 상태: 구현. ‘원문 전체’는 검색 chunk 전체 텍스트이며 전체 원본 파일 뷰어가 아니다. 체크 기록은 영구 저장하지 않는다.
- 향후: 체크리스트 작성·승인 UI, 직원 원본 다운로드는 미구현.
- 관련: REQ-005/012, `ui.py::source_dialog`, `checklist_ui.py`, `context.py`.

## SCR-005 지침서 관리

- 목적/사용자: 관리자에게 문서 현황과 등록·교체·재색인·삭제 제공.
- 입력: 등록 방식, PDF/DOCX/XLSX 파일, 제목, 공통 항목·분류, 원문 개정일, 원본·개인정보 검토 체크. 관리할 문서 선택.
- 버튼: 문서 추가, 저장하고 검색 인덱스 생성, 이 문서 검색 인덱스 재생성, 선택 문서 삭제, 확인 후 지침서 삭제, 등록 중인 모든 문서 재색인.
- 출력: 문서 목록·상태·추출 누락 경고·chunk 수·색인 시각·저장된 오류. 로컬 재색인의 임베딩 재사용 통계 표시.
- 이동: 채팅 ↔ 지침서 관리. 문서 행 선택 → 아래 관리 영역. 삭제 → 확인 대화상자.
- 예외: 미검토 업로드, 파일 형식·크기 오류, OCR/추출 실패, 중복 파일, 임베딩·저장·권한 오류. 일괄 재색인은 실패 건수를 안내.
- 상태: 구현. 원본을 PDF 뷰어로 표시하는 UI는 제공하지 않음.
- 향후: 운영 교체 중 부분 실패의 복구 계약 확인 필요. 이번에 변경하지 않음.
- 관련: REQ-006/007, `admin_ui.py`, 저장소 모듈.

## SCR-006 검색 실패 진단

- 목적/사용자: 관리자가 저장 데이터와 실제 검색 단계 확인.
- 입력: 최대 10개 지침서, 진단 질문, 비교 검색어, AI 최종 답변 재시험 여부(기본 꺼짐).
- 버튼: 실제 검색 파이프라인 진단, BM25 결과 CSV 저장, 전체 진단 JSON 다운로드.
- 출력: 추출·저장 chunk·벡터 점검, BM25/Vector/RRF Top-10, 재정렬 Top-5, 제외 사유, 근거 검사·답변 검증 결과.
- 이동: SCR-005 안의 펼침 영역. 별도 성능 비교 페이지가 아님.
- 예외: 원본 접근 실패도 별도 오류로 기록하고 가능한 검사를 지속. 권한 철회·문서 변경은 결과 제공 중단.
- 상태: 구현. 진단 출력 Top-k는 생성에 사용하는 최종 근거 개수와 다름.
- 향후: RAGAS·BM25/ChromaDB 비교 화면 미구현.
- 관련: REQ-008, `diagnostic_ui.py`, `diagnostics.py`, `search_trace.py`.

## SCR-007 설정 안내·로컬 직원 계정

- 목적/사용자: 관리자가 연결 상태·사용량을 보고 로컬 직원을 관리.
- 입력: 새 직원 아이디·비밀번호, 비활성화할 직원.
- 버튼: 직원 계정 등록, 선택 직원 계정 비활성화.
- 출력: 저장소 종류, 사용량·남은 한도, 현재 대화의 AI 평균 시간, OCR 상태, 로컬 사용자 목록.
- 이동: SCR-005의 ‘관리자 설정 안내 / 직원 계정’ 펼침 영역.
- 예외: 중복 아이디·잘못된 자격 형식·현재 관리자 본인 비활성화 거절.
- 상태: 로컬 관리 UI 구현. 운영 모드에는 Supabase에서 계정·역할을 관리하라는 안내 표시.
- 향후: 앱 내부 운영 계정 관리 미구현. 안내에 있는 `mvp/README.md`는 현재 없으므로 루트 README를 참조해야 함.
- 관련: REQ-010/013, `admin_ui.py`, `auth.py`, `ai.py::Quota`.

## SCR-008 로컬 백업

- 목적/사용자: 관리자가 로컬 복구용 사본 생성.
- 입력: 별도 입력 없음.
- 버튼: 지침서·계정·색인 백업(로컬 원본 저장소 조건).
- 출력: 백업 검증 결과와 저장 경로.
- 이동: SCR-007과 같은 관리 영역.
- 예외: 권한·파일 공간·연결 경로·무결성 오류. 실패 사본은 `INCOMPLETE` 표시.
- 상태: 로컬 백업 구현. Supabase 백업 및 복원 UI 미구현.
- 향후: 실제 복원 절차·복구 훈련은 확인 필요.
- 관련: REQ-014, `operations.py`, `admin_ui.py`.

## 평가 화면과 CLI의 구분

`mvp.evaluate`와 `mvp.evaluate_cases`는 터미널 실행 도구다. 현재 웹 화면에서 공통 RAGAS 비교 점수를 표시하지 않는다. 다른 브랜치의 BM25 일괄 평가 화면도 현재 main의 화면으로 설명하지 않는다.
