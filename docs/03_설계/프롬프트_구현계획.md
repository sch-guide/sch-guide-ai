# 자연어 근거 기반 답변 평가 구현 계획

> **현재 상태:** 이 계획의 구현은 완료되었다. 아래 체크박스는 당시 작업 순서를 보존한 역사 기록이며 현재 진행률을 뜻하지 않는다. 최신 상태는 `docs/00_기획/현재_프로젝트_상태.md`와 `docs/06_변경이력/복구기준점.md`를 기준으로 확인한다.
>
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `v1.0-natural-grounded` YAML Prompt를 기존 controlled generation의 offline/mock 평가 경로에만 연결하고, 기존 extractive 답변과의 raw-free 사람 검수를 가능하게 한다.

**Architecture:** 직접 의존성 `PyYAML`의 `SafeLoader`를 확장한 fail-closed loader가 registry와 버전 파일을 함께 검증하고 정규화된 설정 해시를 만든다. 기존 controlled generation validator 앞단은 이 설정으로 Prompt를 렌더링하지만, 판단 결과는 계속 extractive Answer를 반환하며 Production `generate()` 경로에는 어떠한 import나 호출도 추가하지 않는다.

**Tech Stack:** Python 3.11+, PyYAML 6.x, 표준 라이브러리(`hashlib`, `json`, `pathlib`), 기존 Pydantic·Streamlit·pytest·Ruff

**Spec:** `docs/03_설계/프롬프트_설계서.md`

## Global Constraints

- YAML 파싱은 직접 의존성 `PyYAML>=6,<7`만 사용한다.
- Production `generate()` 및 `src/ai.py`에는 Prompt loader를 연결하지 않는다.
- `publish_controlled=false`, `semantic_support_status="pending"`, `fallback_to_extractive=true`, `retry_count=0`을 fail-closed로 고정한다.
- 후속 질문 구조는 유지하지만 `v1.0-natural-grounded`에서는 `enabled_for_evaluation=false`로 고정한다.
- SourceUnit, citation, AnswerCoverage, `validate_answer()`, number·unit·time·condition·negation·action, branch·phase, source order와 parent atomicity를 완화하지 않는다.
- Production Retrieval, Validator, Gold, fixture, DB, schema를 변경하지 않는다.
- 외부 API/provider 호출을 추가하거나 실행하지 않는다.
- 사람이 읽는 Prompt·runtime 안내·safety rule은 한글로 유지하고, key와 status·purpose·version·strategy 등 코드 계약값은 영어를 유지한다.
- 영어 계약값에는 필요한 경우 한글 YAML comment를 두며, runtime placeholder의 이름과 집합은 변경하지 않는다.
- raw 질문, 병원 원문, 답변 전문, Prompt 본문, provider payload/response를 검수 artifact에 저장하지 않는다.
- Git commit, tag, push를 수행하지 않는다.

- [ ] **Step 4: `src/prompt_config.py`에 최소 loader를 구현한다**

```python
@dataclass(frozen=True)
class LoadedPromptConfig:
    prompt_version: str
    system: str
    instruction: str
    runtime_templates: Mapping[str, str]
    config_sha256: str
    max_statements: int
    publish_controlled: bool
    semantic_support_status: str
    follow_up_enabled: bool


def load_evaluation_prompt(
    version: str | None = None,
    *,
    prompt_root: Path = PROMPT_ROOT,
) -> LoadedPromptConfig:
    root = prompt_root.resolve()
    registry = _read_yaml(root / "registry.yaml")
    selected = version or _require_str(registry, "evaluation_candidate_version")
    entry = _select_unique_entry(registry, selected)
    prompt_path = _resolve_registered_path(root, _require_str(entry, "path"))
    prompt = _read_yaml(prompt_path)
    _validate_evaluation_only_contract(registry, entry, prompt, selected)
    return _build_loaded_prompt(entry, prompt)
```

`_read_yaml()`은 duplicate key를 거부하도록 확장한 `yaml.SafeLoader`만 사용한다. `_resolve_registered_path()`는 등록된 상대 경로를
`resolve()`한 뒤 부모가 `prompt_root.resolve()`와 동일한지 확인한다.
`_validate_evaluation_only_contract()`는 registry의 `production_enabled`가 `false`이고 registry
entry와 version 파일 양쪽의 `publish_controlled`가 `false`, semantic support가 `pending`,
follow-up이 `false`, publication fallback이 `true`, retry가 `0`일 때만 반환한다.

- [ ] **Step 5: 정규화된 config hash를 구현한다**

```python
canonical = json.dumps(
    {"registry_entry": registry_entry, "prompt": prompt_data},
    ensure_ascii=False,
    sort_keys=True,
    separators=(",", ":"),

config_sha256 = hashlib.sha256(canonical).hexdigest()
```

이 해시는 registry의 선택·안전 플래그와 버전 Prompt 의미를 함께 묶고, YAML 공백·줄바꿈 변화에는 영향받지 않는다. artifact에는 Prompt 본문 대신 `prompt_version`과 이 해시만 기록한다.

## Fail-closed 조건

다음 중 하나라도 발생하면 candidate 평가를 중단하고 기존 extractive Answer를 유지한다.

- registry/version 파일 누락, 중복 version, 경로 이탈 또는 YAML parsing 실패
- schema version, prompt version, 상태 또는 안전 플래그 불일치
- `production_enabled=true`, `publish_controlled=true`, semantic support가 `pending`이 아님
- follow-up이 활성화됨
- runtime template 필수 key 누락 또는 알 수 없는 placeholder
- SourceUnit ID 중복·미존재, citation 불일치 또는 coverage 누락
- number·unit·time·condition·exception·negation·prohibition·action 변화
- branch·phase 혼합, source order 또는 parent atomicity 위반
- 사람 검수 record에 허용되지 않은 field, enum, raw text 또는 secret marker 존재

## Production 미연결 보장

loader는 평가 도구가 명시적으로 호출할 때만 실행한다. `src/ai.py`, 루트 `streamlit_app.py`와
Production retrieval 경로에는 import도 feature flag도 추가하지 않는다. `decide_controlled_generation()`은
검증 성공 시에도 `output=extractive_answer`, `publish_controlled=False`,
`reason="semantic_support_pending"`를 유지한다. 따라서 새 YAML은 평가 candidate를 구성하고
검수하는 데만 쓰이며 사용자 답변을 교체할 수 없다.

## Rollback

구현 중 문제가 생기면 신규 loader/review 파일과 그 전용 테스트만 제거하고,
`src/controlled_generation.py`와 `tools/provider_controlled_generation_evaluate.py`의 Prompt builder
signature를 구현 직전 상태로 되돌린다. YAML draft와 설계서는 실행 경로와 분리되어 있으므로
그대로 남겨도 Production 영향은 없다. rollback에서도 Gold, fixture, DB, schema와 기존 평가
artifact는 수정하지 않으며 Git history rewrite를 사용하지 않는다.
