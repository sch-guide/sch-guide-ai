## 복구 방법

기존 작업을 강제로 덮어쓰지 말고 별도 branch에서 확인한다.

```powershell
git fetch origin --tags
git switch -c recovery-v0.9 v0.9
git status
```

이전 기준점이 필요하면 다음을 사용한다.

```powershell
git switch -c recovery-v0.8 v0.8
git status
```

`git reset --hard`와 force push는 기본 복구 절차가 아니다.
