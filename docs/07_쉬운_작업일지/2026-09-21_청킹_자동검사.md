# 2026-09-21 · 청킹 자동검사

## 무엇을 바꿨나

지침서를 검색하기 좋은 작은 조각으로 나눈 뒤, 그 결과에 문제가 없는지 프로그램이 자동으로 확인하도록 만들었습니다.

자동으로 확인하는 항목은 다음과 같습니다.

- 내용이 비어 있는 조각이 있는가
- 검색 모델이 읽을 수 있는 길이보다 긴 조각이 있는가
- 완전히 같은 조각이 중복되었는가
- 여러 페이지에 같은 머리말이 반복되는가
- 내용 없이 제목만 있는 짧은 조각이 몇 개인가

## 문제가 있으면 어떻게 되나

비어 있거나 너무 긴 조각이 있으면 문서를 저장하기 전에 중단합니다. 반복 머리말과 짧은 제목은 문서의 위치를 알려 주는 표지로 쓸 수 있기 때문에 없애지 않고 개수만 알려 줍니다.

## 검색 결과가 달라지나

이번 작업은 청킹 문장, 순서, 길이, 겹치는 범위를 바꾸지 않았습니다. 기존 방식과 새 방식으로 만든 청크 문장을 직접 비교했고 모두 같았습니다. 진정간호 일반화 회귀 질문 45개도 새 방식에서 45개 모두 통과했습니다. 이는 별도의 v1 운영 UAT 36건과 다른 검사입니다.

## 내가 화면에서 보는 내용

관리자 화면에서 다음처럼 볼 수 있습니다.

> 자동검사 통과 · 반복 머리말 7개 · 짧은 제목 2개 · 같은 내용 0개 · 가장 긴 조각 98/110

기존 문서는 바로 바뀌지 않습니다. 해당 문서를 재색인하면 검사 결과가 새로 생깁니다.
