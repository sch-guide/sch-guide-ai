# SCHAT Product Requirements

- 현재 상태: [`docs/현재정본/00_현재상태.md`](현재정본/00_현재상태.md)
- 전체 구조: [`docs/현재정본/02_전체구조.md`](현재정본/02_전체구조.md)
- 테스트 현황: [`docs/현재정본/06_테스트현황.md`](현재정본/06_테스트현황.md)
- 상세 변경 이력: [`변경이력.md`](../변경이력.md)
- 복구 기준점: [`복구기준점.md`](../복구기준점.md)
