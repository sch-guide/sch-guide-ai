# SCHAT 공식 문서 안내

이 `docs/` 폴더는 SCHAT의 **유일한 공식 문서 정본**이다. 요구사항, 설계, 테스트 결과와
운영 판정이 다른 위치의 문서와 다르면 이 폴더의 현재 문서를 기준으로 한다.

`docs_view/`는 사람이 편하게 읽기 위한 렌더링·열람용 복사본이다. `docs_view/`의 파일을
직접 편집해 공식 요구사항이나 설계를 변경하지 않는다.

## 과거 문서

`bm25/`, `rag/`, `superpowers/`는 과거 구현·평가 이력을 보존하는 임시 위치다. 공식 현재
판정은 위 표의 정본 문서를 사용한다. 과거 문서는 구조 개편 3단계에서 `workspace/과거작업/`
아래로 이동할 예정이다.
