## 현재 Production

```text
질문 분석
  → BM25 + MiniLM semantic/vector
  → RRF
  → 기존 reranker
  → evidence gate / parent atomicity
  → Facet-slot SourceUnit selection
  → server reconstruction
  → validate_answer()
  → presentation sidecar
  → Streamlit 답변·출처 UI
```

- Retrieval: `BM25 + MiniLM semantic/vector + RRF + existing reranker`
- Production embedding: `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, 384d
- Facet-slot distinct SourceUnit limit: 16
- Answer statement limit: 16
- Q006 out-of-scope: provider transport 0회
- Citation, number, unit, time, condition, negation, action, branch, phase, source-order validator 유지

## v0.9에서 달라진 것

1. Frozen 90문항으로 reranker 병목을 분석했다. BM25+E5 raw RRF가 가장 정확했지만 E5 지연·메모리와 기존 안전 reranker 우회 문제가 있어 production retrieval은 변경하지 않았다.
2. Sparse PDF table을 substantive catalog parent rows로 안전하게 fallback하고 숫자·단위·시간을 table-only search에서 우선했다. 승인 table 5문항 Hit@10은 1.0이다.
3. Controlled generation이 schema/invariant 실패 또는 semantic support 미확정 시 retry 없이 기존 extractive Answer를 유지하는 결정을 명시했다.
4. Image+table 요청은 `mixed` 후보로 기록하지만 image가 포함되면 `pending_image_review`로 유지한다.
