# SCHAT 답변 생성

## 현재 Production 답변

Production은 선택된 SourceUnit ID를 서버가 다음처럼 복원한다.

- `Statement.text = SourceUnit.exact_text`
- `Evidence.quote = SourceUnit.exact_text`
- `Evidence.chunk_id = SourceUnit.chunk_id`

그 뒤 AnswerCoverage와 `validate_answer()` 전체를 통과한 Answer만 UI에 전달한다.

## Presentation sidecar

Presentation sidecar는 Answer를 바꾸지 않고 다음 metadata만 제공한다.

- statement index
- source-unit ID
- branch
- phase
- source order
- leading marker
- intent / answer format

질문 유형에 따라 paragraph, procedure steps, checklist, warning bullets, comparison table, summary, product heading, temporal/branch heading을 표시한다. Statement text, quote, citation, source order는 그대로다.

## Controlled generation 상태

Provider-neutral schema, prompt, request-scoped SourceUnit enum, supporting IDs, citation 재생성, invariant validator와 Mock은 준비됐다.

`decide_controlled_generation()`의 현재 정책:

| 상태 | 공개 결과 | Retry |
|---|---|---:|
| Schema 오류 | 기존 extractive Answer | 0 |
| Unknown/duplicate evidence | 기존 extractive Answer | 0 |
| Number/unit/condition/negation 오류 | 기존 extractive Answer | 0 |
| Branch/phase mixing 또는 coverage 실패 | 기존 extractive Answer | 0 |
| 모든 구조 검증 통과, semantic support 미확정 | 기존 extractive Answer | 0 |

Caller가 boolean으로 semantic 검증을 우회하는 경로는 없다. 승인된 semantic entailment validator가 구현·검증되기 전에는 controlled candidate를 사용자에게 공개하지 않는다.

## Validator

현재 안전 계약은 다음을 fail closed로 검증한다.

- Citation / exact source sentence
- Number / unit / time
- Condition / contraindication / negation
- Unsupported action / synthesis
- Branch / phase
- Source order / duplicate evidence
- PromptCoverage / AnswerCoverage

Formatting 오류만 의미 변경 없이 수정할 수 있다. 임상 의미 변경 가능성이 있으면 기존 extractive Answer 또는 abstention을 사용한다.

## Provider 상태

- Groq/Gemini 실제 호출: 이번 작업 0회
- 병원 데이터 외부 전송: 0회
- Live controlled generation: 정책 승인 대기
- 기존 승인된 SourceUnit selection 경로는 변경하지 않음
