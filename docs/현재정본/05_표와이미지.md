# SCHAT 표와 이미지

## 표

| 항목 | 상태 | 쉬운 설명 |
|---|---|---|
| Table inventory | 완료 | 수혈 문서에서 구조화 대상 표를 찾았다. |
| Table evidence | 평가 완료 | 5개 표와 33개 행을 구조화했다. |
| Header/row/cell 관계 | 평가 완료 | 추출 가능한 관계를 그대로 보존하고 추측하지 않는다. |
| Table retrieval | 평가 완료 | 표 전체가 아니라 header+row 중심 로컬 검색을 검증했다. |
| Table citation | 완료 | 문서, 페이지, table ID, row index를 함께 표시한다. |
| Table UI | 완료 | 로컬 Streamlit evaluation UI에서 exact cell/row와 citation을 볼 수 있다. |
| Production 연결 | 보류 | 5개 승인 case 중 Hit@10 0.8이고 개선이 확정되지 않아 서비스 답변에는 연결하지 않았다. |
| MM003 | 평가 중 | 1건 miss의 gold와 row 연결을 검토해야 한다. |

### 현재 숫자

- Structured tables: 5
- Structured rows: 33
- `pdf_cells`: 3 tables
- `catalog_row_fallback`: 2 tables
- Approved table cases: 5
- Hit@10: 0.8

### 표 안전 계약

- Header/cell 관계를 임의로 만들지 않는다.
- 표의 숫자·단위·시간 값을 생성하거나 보정하지 않는다.
- Exact parsed cell/row만 화면에 표시한다.
- Artifact에는 원문 대신 ID, bbox, fingerprint와 SHA-256을 저장한다.
- 표 근거를 production answerability에 연결하려면 별도 성능·회귀 승인 절차를 거친다.

### 로컬 검수 화면

```powershell
.\.venv\Scripts\python.exe -m streamlit run tools\table_evidence_app.py
```

이 UI는 evaluation-only이며 외부 API를 호출하거나 source text를 artifact에 저장하지 않는다.

## 이미지·도식

| 항목 | 상태 | 쉬운 설명 |
|---|---|---|
| Figure metadata candidates | 평가 완료 | page/bbox/caption/nearby text/fingerprint 후보 55건을 기록했다. |
| 장식 이미지 제외 기준 | 완료 | flowchart·algorithm·decision tree·procedure diagram·clinical figure만 대상으로 삼는다. |
| Workflow 해석 | 사람 검수 필요 | 화살표 방향과 단계 순서를 자동 확정하지 않았다. |
| TF027 | 사람 검수 필요 | 이미지의 순차 임상 의미를 사람이 승인하기 전 aggregate/production에서 제외한다. |
| OCR/diagram parser | 보류 | 승인된 image-dependent gold가 생긴 뒤 안전성을 평가한다. |
| Vision API | 보류 | 실제 호출 0회. 외부 전송 승인 전 사용하지 않는다. |
| Image answer/citation UI | 보류 | 검증된 구조화 근거가 없으므로 production UI에 연결하지 않았다. |

### 왜 사람 검수가 필요한가

도식의 화살표 하나가 다른 방향으로 해석되거나 단계가 바뀌면 임상 의미가 달라질 수 있다. 숫자와 단위가 흐리거나 workflow 순서가 불확실한 상태를 모델이 채우게 하지 않고 `needs_human_review=true`로 유지한다.

## Multimodal routing

`mvp/evidence_routing.py`는 질문에서 `text`, `table`, `image`, `mixed` 후보 metadata를 만들 수 있다. 그러나 현재 이 metadata는:

- Production retrieval을 바꾸지 않는다.
- Evidence gate를 바꾸지 않는다.
- Answerability를 바꾸지 않는다.
- 모든 질문에서 모든 retriever를 실행하지 않는다.

즉 향후 연결을 위한 준비 단계이며, 현재 답변 경로의 임상 판단에는 사용하지 않는다.
