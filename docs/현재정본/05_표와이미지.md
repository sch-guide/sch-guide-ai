# SCHAT 표와 이미지 현재 상태

## Structured table

| 항목 | 현재 값 |
|---|---:|
| Table records | 5 |
| Search rows | 38 |
| Approved table cases | 5 |
| Hit@10 | 1.0 |
| MM003 first gold rank | 2 |

Table citation은 document/page/table ID/row index를 보존한다. Exact cell/row text는
로컬 UI에서만 표시하며 artifact에는 ID, bbox, fingerprint와 hash만 저장한다. Production
repository schema에는 table persistence가 아직 연결되지 않았다.

운영 UAT의 table/mixed 질문은 local structured table 후보를 함께 확인한다. 후보가 발견돼도
`candidate_found_not_human_gold`로 기록하며, 사람이 승인한 Gold로 자동 승격하지 않는다.

## TF027 image/diagram

- 원본 checklist 10개 항목: 모두 `unreviewed`
- 확인됨: 0/10
- 1차 reviewer: 미완료
- 2차 reviewer: 미완료
- `needs_human_review=true`
- `production_gold_approved=false`
- `included_in_aggregate=false`
- Vision/provider API 호출: 0회

로컬 검수 화면:

```powershell
.\.venv\Scripts\streamlit.exe run tools/tf027_human_review_app.py
```

화면은 왼쪽에 원본 PDF page와 후보 bbox 오버레이, 오른쪽에 10개 검수 항목을 표시한다.
사람이 `확인됨/불확실/해당 없음`을 선택하고 직접 확인한 node, edge, branch, sequence,
number, unit, time만 입력한다. 화면을 여는 것만으로는 파일을 만들지 않는다.

저장 버튼을 누르면 원본 checklist를 덮어쓰지 않고 아래 별도 fixture에 저장한다.

`tests/fixtures/tf027_image_human_review_reviewed.json`

모든 필수 값, 불확실성 0건, 서로 다른 reviewer 2명의 승인이 있을 때만 Production image
Gold 플래그가 파생된다. 사람 검수 전에는 image retrieval aggregate나 production
answerability에 연결하지 않는다.

## Multimodal routing

Text/table/image/mixed evidence metadata는 유지하지만 image pending 상태는 retrieval
answerability에 연결하지 않는다. 모든 질문에서 모든 retriever를 실행하지 않는다.
