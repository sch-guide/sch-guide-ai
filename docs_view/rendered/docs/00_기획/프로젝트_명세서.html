열람용 복사본공식 정본은 docs/입니다.

SCHAT 프로젝트 명세서

docs/는 SCHAT의 유일한 공식 문서 정본이다. docs_view/는 렌더링·열람용 복사본이며 요구사항과 설계 판정의 기준으로 사용하지 않는다.

  • 문서 안내: `docs/README.md`
  • 현재 상태: `현재_프로젝트_상태.md`
  • 현재 요구사항: `통합_요구사항서.md`
  • 전체 구조: `시스템_구조_요약.md`
  • 검색 구조: `검색_Retrieval_설계서.md`
  • 답변 생성: `답변생성_설계서.md`
  • 표와 이미지: `표_이미지_설계서.md`
  • 테스트 현황: `테스트_현황.md`
  • 변경 이력: `변경이력.md`
  • 복구 기준점: `복구기준점.md`

현재 공식 안정 복구 기준점은 v0.9다. 현재 코드는 최종 READY 재판정 전 상태이며, 운영 UAT 36/36과 retrieval 무회귀를 확인했다. Positive Gold는 21건 승인·11건 deferred, TF027은 10개 항목의 1차 사람 검수를 마쳤으나 최종 판정은 reject로 Production에서 제외했다. Provider/LLM judge 평가는 승인 범위가 남아 pending이다. 사용자 승인 없이 commit, tag, push하지 않는다.
