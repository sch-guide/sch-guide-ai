Table citation은 document/page/table ID/row index를 보존한다. Exact cell/row text는 로컬 UI에서만 표시하며 artifact에는 ID, bbox, fingerprint와 hash만 저장한다. Production repository schema에는 table persistence가 아직 연결되지 않았다.

운영 UAT의 table/mixed 질문은 local structured table 후보를 함께 확인한다. 후보가 발견돼도 candidate_found_not_human_gold로 기록하며, 사람이 승인한 Gold로 자동 승격하지 않는다.

저장 버튼을 누르면 원본 checklist를 덮어쓰지 않고 아래 별도 fixture에 저장한다.

tests/fixtures/tf027_image_human_review_reviewed.json

모든 필수 값, 불확실성 0건, 서로 다른 reviewer 2명의 승인이 있을 때만 Production image Gold 플래그가 파생된다. 현재는 1차 검수를 마쳤지만 불확실 항목과 2차 승인 미완료로 최종 reject 되었으며 image retrieval aggregate나 production answerability에 연결하지 않는다.
