﻿# 자연어 근거 기반 답변 평가 구현 계획

현재 상태: 이 계획의 구현은 완료되었다. 아래 체크박스는 당시 작업 순서를 보존한 역사 기록이며 현재 진행률을 뜻하지 않는다. 최신 상태는 docs/00_기획/현재_프로젝트_상태.md와 docs/06_변경이력/복구기준점.md를 기준으로 확인한다. For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: v1.0-natural-grounded YAML Prompt를 기존 controlled generation의 offline/mock 평가 경로에만 연결하고, 기존 extractive 답변과의 raw-free 사람 검수를 가능하게 한다.

Architecture: 직접 의존성 PyYAML의 SafeLoader를 확장한 fail-closed loader가 registry와 버전 파일을 함께 검증하고 정규화된 설정 해시를 만든다. 기존 controlled generation validator 앞단은 이 설정으로 Prompt를 렌더링하지만, 판단 결과는 계속 extractive Answer를 반환하며 Production generate() 경로에는 어떠한 import나 호출도 추가하지 않는다.

Tech Stack: Python 3.11+, PyYAML 6.x, 표준 라이브러리(hashlib, json, pathlib), 기존 Pydantic·Streamlit·pytest·Ruff

Spec: docs/03_설계/프롬프트_설계서.md

Global Constraints

  • YAML 파싱은 직접 의존성 PyYAML>=6,<7만 사용한다.
  • Production generate() 및 src/ai.py에는 Prompt loader를 연결하지 않는다.
  • publish_controlled=false, semantic_support_status="pending", fallback_to_extractive=true, retry_count=0을 fail-closed로 고정한다.
  • 후속 질문 구조는 유지하지만 v1.0-natural-grounded에서는 enabled_for_evaluation=false로 고정한다.
  • SourceUnit, citation, AnswerCoverage, validate_answer(), number·unit·time·condition·negation·action, branch·phase, source order와 parent atomicity를 완화하지 않는다.
  • Production Retrieval, Validator, Gold, fixture, DB, schema를 변경하지 않는다.
  • 외부 API/provider 호출을 추가하거나 실행하지 않는다.
  • 사람이 읽는 Prompt·runtime 안내·safety rule은 한글로 유지하고, key와 status·purpose·version·strategy 등 코드 계약값은 영어를 유지한다.
  • 영어 계약값에는 필요한 경우 한글 YAML comment를 두며, runtime placeholder의 이름과 집합은 변경하지 않는다.
  • raw 질문, 병원 원문, 답변 전문, Prompt 본문, provider payload/response를 검수 artifact에 저장하지 않는다.
  • Git commit, tag, push를 수행하지 않는다.

@dataclass(frozen=True)
class LoadedPromptConfig:
    prompt_version: str
    system: str
    instruction: str
    runtime_templates: Mapping[str, str]
    config_sha256: str
    max_statements: int
    publish_controlled: bool
    semantic_support_status: str
    follow_up_enabled: bool


def load_evaluation_prompt(
    version: str | None = None,
    *,
    prompt_root: Path = PROMPT_ROOT,
) -> LoadedPromptConfig:
    root = prompt_root.resolve()
    registry = _read_yaml(root / "registry.yaml")
    selected = version or _require_str(registry, "evaluation_candidate_version")
    entry = _select_unique_entry(registry, selected)
    prompt_path = _resolve_registered_path(root, _require_str(entry, "path"))
    prompt = _read_yaml(prompt_path)
    _validate_evaluation_only_contract(registry, entry, prompt, selected)
    return _build_loaded_prompt(entry, prompt)

_read_yaml()은 duplicate key를 거부하도록 확장한 yaml.SafeLoader만 사용한다. _resolve_registered_path()는 등록된 상대 경로를 resolve()한 뒤 부모가 prompt_root.resolve()와 동일한지 확인한다. _validate_evaluation_only_contract()는 registry의 production_enabled가 false이고 registry entry와 version 파일 양쪽의 publish_controlled가 false, semantic support가 pending, follow-up이 false, publication fallback이 true, retry가 0일 때만 반환한다.
