2026-09-12~17 · 검색과 근거 찾기

이날 하려고 했던 일

간호사가 질문했을 때 병원 지침서에서 관련 부분을 정확히 찾는 기본 기능을 만드는 것이 목표였습니다.

실제로 한 일

  • 먼저 단어가 정확히 일치하는 부분을 찾는 BM25 검색을 만들고 시험했습니다.
  • 긴 지침서를 검색하기 좋은 작은 단위로 나누고, 각 단위에 문서·페이지·순서 정보를 붙였습니다.
  • 질문 표현이 지침서와 조금 달라도 찾을 수 있도록 의미 기반 검색을 함께 시험했습니다.
  • 여러 검색 결과를 합치고 다시 정렬하는 현재 Hybrid 검색 구조를 안정화했습니다.
  • 답변에 사용할 수 있는 근거를 SourceUnit이라는 작은 근거 단위로 관리했습니다.
  • 표와 이미지가 필요한 질문은 일반 문장 검색과 구분해 다루기 시작했습니다.

왜 필요했나

AI가 말을 잘 만드는 것보다 먼저, 올바른 지침서 부분을 찾는 것이 중요하기 때문입니다. 잘못된 근거를 찾으면 이후 답변 생성이 아무리 자연스러워도 안전한 답변이 될 수 없습니다.

확인된 결과

  • BM25 검색 기준선이 만들어졌습니다.
  • 단어 검색과 의미 검색을 함께 쓰는 Hybrid 구조가 실제 코드에 들어갔습니다.
  • 어떤 근거를 사용했는지 출처를 연결할 수 있게 됐습니다.
  • 근거가 부족하거나 질문 범위가 다르면 답변하지 않는 안전 경계가 추가됐습니다.

아직 해결되지 않았던 문제

  • 검색 방식별 성능을 똑같은 조건에서 비교하지 않은 상태였습니다.
  • 답변 생성 AI가 근거의 숫자·조건·행동을 정확히 보존하는지 더 강한 검사가 필요했습니다.

다음에 할 일

사람이 승인한 질문과 근거를 기준으로 BM25, ChromaDB, Hybrid를 공정하게 비교하고 답변 안전성을 검증하는 단계로 넘어가기로 했습니다.

핵심 한 줄

이 기간에는 “AI가 답하기 전에, 지침서에서 맞는 근거를 찾는 기반”을 만들었습니다.
