가장 중요한 구분

검색이 잘된다는 것과 답변이 안전하다는 것은 다릅니다

  • 검색 평가는 필요한 지침서 부분을 잘 찾았는지 확인합니다.
  • 답변 평가는 찾은 근거의 의미를 AI가 바꾸지 않았는지 확인합니다.
  • 두 단계가 모두 통과해야 실제 사용 준비가 됐다고 판단할 수 있습니다.

Production과 Evaluation-only는 다릅니다

  • Production: 실제 웹 시연이나 서비스 경로에서 사용하는 기능
  • Evaluation-only: 비교와 실험을 위해 따로 만든 기능으로 실제 서비스에는 연결하지 않음

ChromaDB-only 평가와 Gemini 관련 진단 도구는 비교·검증 목적의 evaluation-only 경로입니다.

Gemini 임베딩과 Gemini 답변 생성은 다릅니다

  • Gemini Embedding 2: 질문과 문서를 검색용 숫자 벡터로 바꿉니다.
  • Gemini 답변 생성: 찾은 근거를 읽고 자연어 답변을 만듭니다.
  • 같은 회사의 모델이지만 역할과 평가 기준이 다르므로 작업일지에서도 분리해 기록합니다.
