RAGAS와 Live 평가는 어디까지 할 것인가

결론

현재는 외부 AI를 부르지 않아도 계산할 수 있는 검색 점수와 안전 검사는 완료했습니다. Faithfulness와 Answer Relevancy는 질문·답변·근거를 외부 평가 AI에 보내야 하므로 자동으로 실행하지 않습니다. 병원 데이터 전송 범위와 비용을 사람이 승인한 뒤에만 실행합니다.

이미 완료된 평가

평가의미현재 상태
Hit@1/3/5/10정답 근거가 상위 검색 결과 안에 있는지완료
MRR정답 근거가 얼마나 앞쪽에 나오는지완료
Recall·Precision필요한 근거를 얼마나 찾고 불필요한 근거를 얼마나 줄였는지완료
ID Context Precision·Recall원문 대신 안전한 근거 ID로 계산한 검색 품질완료
Citation·숫자·단위·시간 등답변이 근거와 안전 규칙을 지켰는지로컬 검사 유지
Out-of-scope zero-call범위 밖 질문에서 외부 AI를 호출하지 않는지완료

아직 실행하지 않는 평가

평가필요한 입력현재 결정
Faithfulness생성 답변과 근거 문맥외부 전송 승인 전 pending
Answer Relevancy승인 질문과 생성 답변외부 전송 승인 전 pending
LLM Context Precision·Recall질문·근거와 judge 모델ID 기반 점수와 구분해 pending

실행 전 반드시 정할 것

  1. 외부로 보낼 수 있는 데이터가 질문·근거·답변 중 어디까지인지 정합니다.
  2. 승인된 Positive Gold 21건만 사용할지, 먼저 대표 subset을 사용할지 정합니다.
  3. 같은 judge 모델과 같은 prompt를 모든 비교 대상에 적용합니다.
  4. 원문·전체 prompt·raw response·API key는 산출물에 저장하지 않습니다.
  5. 실제 안전 실패가 한 건이라도 나오면 확대 실행을 중단합니다.

권장 실행 순서

로컬 synthetic 검사 → 승인된 대표 subset → 사람 의미 검수 → 승인 21건 확대

이 문서는 외부 호출을 승인하는 문서가 아닙니다. 현재 외부 API 호출 수는 0회입니다.
