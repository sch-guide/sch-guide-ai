SCHAT 공식 문서 안내

이 docs/ 폴더는 SCHAT의 유일한 공식 문서 정본이다. 요구사항, 설계, 테스트 결과와 운영 판정이 다른 위치의 문서와 다르면 이 폴더의 현재 문서를 기준으로 한다.

docs_view/는 사람이 편하게 읽기 위한 렌더링·열람용 복사본이다. docs_view/의 파일을 직접 편집해 공식 요구사항이나 설계를 변경하지 않는다.
