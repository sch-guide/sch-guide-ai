SRC 청킹 자동검사 설계

목표

현재 src 청킹 결과의 내용을 바꾸지 않고, 문서 등록·재색인 때 객관적인 품질 문제를 자동으로 검사하고 관리자에게 쉬운 한국어로 보여준다.

바뀌는 것

  • 빈 조각, 110토큰 초과 조각, 완전히 같은 중복 조각을 자동으로 센다.
  • 여러 페이지 가장자리에 반복되는 짧은 머리말과 제목만 있는 조각을 참고 수치로 센다.
  • 빈 조각 또는 110토큰 초과 조각이 있으면 저장 전에 중단한다.
  • 검사 결과를 문서 메타데이터에 저장하고 관리자 화면에서 쉬운 문장으로 표시한다.
  • 새 청킹 버전은 5로 표시한다.

바뀌지 않는 것

  • 청크의 원문, 순서, 크기, 겹침 규칙을 바꾸지 않는다.
  • 기존 검색·답변 선택 규칙을 바꾸지 않는다.
  • 기존 문서를 자동으로 재색인하거나 교체하지 않는다.
  • 환자·병원 문서를 외부 서비스로 보내지 않는다.

운영 방식

기존 문서는 검사 결과가 없는 상태로 계속 사용할 수 있다. 관리자가 해당 문서를 재색인하면 그때 자동검사 결과가 생성된다.
