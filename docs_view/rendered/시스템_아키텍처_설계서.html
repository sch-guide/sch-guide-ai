04 · GENERATION SAFETY

생성보다 선택, 선택보다 검증

Groq production 경로는 SourceUnit ID 선택기로 제한됩니다.

CONTRACT

Request-local IDs

Evidence group/facet마다 선택 가능한 SourceUnit ID가 schema enum으로 닫힙니다.

RECONSTRUCTION

Exact source text

서버가 선택 ID를 원문과 chunk citation으로 복원합니다. Provider 문장을 그대로 게시하지 않습니다.

VALIDATION

Fail closed

인용, 숫자, 단위, 행위, 순서, 문서·entity coverage가 하나라도 실패하면 결과를 표시하지 않습니다.

05 · SCOPE BOUNDARY

Production과 Evaluation-only

같은 저장소에 존재한다는 사실과 운영 경로에 연결됐다는 사실을 분리합니다.

Production

현재 실행 경로

  • 자체 BM25 + MiniLM semantic/vector
  • FAISS local / pgvector staff
  • RRF + 기존 규칙 기반 reranker
  • Context expansion / parent atomicity
  • SourceUnit ID 선택 → exact 재구성
  • 기존 validator + AnswerCoverage
Evaluation / Pending

운영 미연결

  • Controlled paraphrase — semantic support pending
  • Structured Table Retrieval — local evaluation tool
  • Image routing — metadata only
  • TF027 — Production image Gold 제외
  • E5 — evaluation-only
  • ChromaDB — 별도 평가 환경
Controlled paraphrase: 형식·ID·수치·단위·조건·부정 검증을 통과해도 semantic support가 미확정이므로 publish_controlled=false, extractive fallback을 유지합니다.
