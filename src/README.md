# src 폴더 안내

> 개발자가 아닌 사용자를 위한 안내입니다.

`src`는 **실제 웹앱이 작동하는 핵심 프로그램**이 들어 있는 폴더입니다. 이 안의 파일은 서로 연결되어 있으므로 이름을 바꾸거나 삭제하지 않는 것이 안전합니다.

주로 확인할 파일은 다음과 같습니다.

| 파일 | 쉬운 설명 | 직접 수정 권장 여부 |
|---|---|---|
| `app.py` | 웹앱을 시작하는 중심 파일 | 아니요 |
| `ui.py`, `answer_ui.py`, `admin_ui.py` | 사용자·답변·관리자 화면 | 개발 작업 때만 |
| `query.py` | 사용자의 질문을 검색하기 좋은 형태로 정리 | 아니요 |
| `retrieval.py`, `library.py` | 관련 지침서 내용을 검색 | 아니요 |
| `evidence.py`, `context.py` | 답변에 사용할 근거를 고르고 정리 | 아니요 |
| `ai.py`, `controlled_generation.py` | 근거 범위 안에서 AI 답변을 구성 | 아니요 |
| `grounding.py` | 답변이 근거와 맞는지 안전 검사 | 아니요 |
| `settings.py`, `.env.example` | 실행 설정의 이름과 기본값 안내 | 실제 API 키 입력 금지 |
| `requirements.txt` | 실행에 필요한 프로그램 목록 | 보통 수정하지 않음 |
| `schema.sql`, `migrations/` | 데이터베이스 구조 | 승인 없이 실행·수정 금지 |

전체 설명은 [프로그램 파일을 쉽게 찾아보는 안내서](../docs/00_기획/프로그램_파일_쉬운_안내.md)를 확인하세요.
