# tests 폴더 안내

> 개발자가 아닌 사용자를 위한 안내입니다.

`tests`는 **기능이 고장 나지 않았는지 자동 확인하는 검사**가 들어 있는 폴더입니다. 앱에서 직접 실행하는 기능이 아니라, 변경 후 기존 기능이 유지되는지 확인하는 안전망입니다.

파일 이름은 대부분 `test_`로 시작합니다.

| 이름에 포함된 말 | 쉬운 설명 |
|---|---|
| `retrieval`, `bm25`, `chroma` | 검색 결과가 올바른지 확인 |
| `evidence`, `source_unit` | 근거 선택과 출처 연결 확인 |
| `citation` | 답변의 출처 표시 확인 |
| `controlled_generation`, `prompt` | AI 답변이 근거 의미를 보존하는지 확인 |
| `number`, `unit`, `time`, `condition` | 숫자·단위·시간·조건 안전 검사 |
| `uat` | 실제 사용 상황을 가정한 종합 검사 |
| `docs_view` | 쉬운 문서 화면이 정상 생성되는지 확인 |
| `workspace_security_cleanup` | 민감한 원문이 작업 공간에 남지 않는지 확인 |
| `fixtures/` | 테스트가 사용할 승인된 예시 입력과 정답 기준 |

테스트 실패는 곧바로 “서비스 전체가 고장났다”는 뜻은 아닙니다. 어떤 검사에서 무엇을 기대했는지 확인한 뒤 원인을 구분해야 합니다.

전체 설명은 [프로그램 파일을 쉽게 찾아보는 안내서](../docs/00_기획/프로그램_파일_쉬운_안내.md)를 확인하세요.
