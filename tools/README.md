# tools 폴더 안내

> 개발자가 아닌 사용자를 위한 안내입니다.

`tools`는 **평가·검수·문서 생성에 사용하는 보조 도구**가 들어 있는 폴더입니다. 실제 사용자 웹앱의 중심 코드는 아니지만, 잘못 실행하면 외부 API 호출이나 평가 결과 생성이 일어날 수 있으므로 설명을 확인한 뒤 사용해야 합니다.

| 파일 이름의 형태 | 쉬운 설명 | 주의사항 |
|---|---|---|
| `*_evaluate.py` | 검색 또는 답변 품질을 측정 | Live가 붙으면 외부 API 승인 필요 |
| `*_review.py` | 사람 검수에 필요한 결과 준비 | 원문 저장 정책 확인 |
| `*_review_app.py` | 로컬 사람 검수 화면 실행 | 외부 공개 금지 |
| `build_docs_view.py` | `docs` 문서를 읽기 쉬운 HTML 화면으로 변환 | 안전하게 실행 가능 |
| `workspace_security_cleanup.py` | 임시 작업 공간에 민감한 원문이 남았는지 검사·정리 | 삭제 범위를 확인하고 실행 |
| `retrieval_3way_compare.py` | BM25·ChromaDB·현재 Hybrid 검색 결과 비교 | 평가 전용 |
| `schat_v1_release_readiness.py` | 배포 준비 조건을 종합 확인 | 자동 배포·Git 작업은 하지 않음 |

파일명에 `live`, `groq`, `gemini`, `provider`가 있으면 외부 서비스와 연결될 가능성이 있습니다. 사용자 승인 없이 실행하지 않습니다.

전체 설명은 [프로그램 파일을 쉽게 찾아보는 안내서](../docs/00_기획/프로그램_파일_쉬운_안내.md)를 확인하세요.
